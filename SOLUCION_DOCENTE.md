# Lista de verificación docente

- `git status` final debe indicar `nothing to commit, working tree clean`.
- `git log --oneline --graph --decorate --all` debe mostrar merges con dos padres.
- README.md debe conservar un único título sin marcadores de conflicto.
- El dataset es sintético y está pensado para práctica local, no para evaluación científica.
- Las métricas variarán si se cambia el CSV o la versión de librerías.
